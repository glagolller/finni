## Размещение материалов

`docs/start/` — базовые требования и планы; `docs/contracts/` — актуальная согласованная спецификация; `docs/decisions/` — решения; `docs/practice/frontend/` и `docs/practice/logic/` — фактические журналы без персональных реквизитов; `evidence/` — доказательства; `delivery/` — описи и ссылки сдачи.

Исходные PDF ТЗ, полная переписка/пакеты передачи, личные бланки и заполненные учебные документы остаются вне репозитория. Частный репозиторий не заменяет выяснение условий доступа экспертов и обращения с конкурсной информацией.

## Запуск

Каркас требует Flutter 3.47.5 / Dart 3.13.4. После установки toolchain:

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

Точка входа намеренно показывает пустой root: экраны добавляет сторона интерфейса. Подробности и Android-блокеры перечислены в [BUILD.md](BUILD.md).

Актуальный график: [24–29 сентября](docs/setup/PLAN-2026-09-24.md).

Рабочая экономика/SQLite еще не подключены. Отдельный main_preview.dart содержит только фиксированные сценарии для разработки и запрещен в release.
