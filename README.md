## Что реализовано

Создание питомца: три формы, три окраски, три стадии роста. План и факт бюджета, каталог из восьми предметов, три цели, шесть интерактивных заданий. История, настройки анимации, раздел взрослого со сбросом демо и удалением профиля. На главной — следующий шаг и список дел по состоянию настоящего LogicService. SQLite сохраняет прогресс и защищает от повторного списания.

Регистрации, собственного сервера, рекламы, реальных платежей, аналитических SDK и облачной синхронизации нет. Учебный контент расположен в `assets/content/`, интерфейс в `lib/ui/`, логика в `lib/domain/`, хранение в `lib/data/`.

## Запуск из исходников

Flutter 3.47.5 / Dart 3.13.4. Для Android JDK 17 и SDK 36. Установить зависимости, выполнить проверки и запустить приложение:

```sh
flutter pub get
flutter analyze --no-pub
flutter test --no-pub
flutter run --target lib/main.dart
```

[Подробная сборка и локальная подпись](BUILD.md). Ключ release хранится у участника, отвечающего за сборку, вне репозитория. Debug подписан другим ключом и не обновляет release обычной установкой.
