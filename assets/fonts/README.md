# Встроенные шрифты

Загружены 25.09.2026 из официального репозитория Google Fonts:
- Pangolin-Regular.ttf: https://github.com/google/fonts/tree/main/ofl/pangolin
- Neucha.ttf: https://github.com/google/fonts/tree/main/ofl/neucha

Оба распространяются по SIL Open Font License 1.1. Полные тексты и уведомления авторов в Pangolin-OFL.txt / Neucha-OFL.txt. Файлы шрифтов не изменены. Используются локально в Flutter и HTML, без CDN. Основной текст — системный шрифт; Segoe UI в тестовых PNG взят из установленной Windows только для проверки и в репозиторий не включён.
