# Передача ДК: каталоги и взрослый раздел

Ветка frontend/service-integration. Получить актуальные изменения обычным merge, без reset/force.

Изменения Ф: убраны переключатель звука и SystemSound.click (собственных эффектов нет); 8+7 заменено удержанием кнопки; доступные задания показаны первыми, выполненные в сворачиваемом блоке; будущие/купленные товары скрыты, лимит и закрытый период имеют заглушки; фон результата покупки соответствует категории. soundEnabled в контракте сохранён, другие настройки продолжают сохранять его значение. ТЗ допускает отсутствие звуков и требует простой барьер, не арифметику. Tutorial/миссии не добавлены.

Контракт RC2.1, экономика, SQLite, Android, pubspec/lock и контент не менялись. При недостатке средств доступный по периоду товар остаётся видимым, отказ объясняет сервис. Ограничения этапов не введены на стороне UI.

Проверки Ф: flutter analyze --no-pub — 0; flutter test --no-pub --dart-define=FINNI_CAPTURE=true — 20/20. Дополнительные assertions: longPress против обычного tap, отсутствие будущего обеда в периоде 1, заглушка лимита, все выполненные задания, отсутствие переключателя звука, оранжевый/синий фон. Пять периодов: итог 5/25, 15 баллов, grown. Скриншоты evidence/ui-catalog, описание docs/ux/CATALOG-POLISH.md.

Просьба пересобрать debug из lib/main.dart с прежними подписью и package для обновления без потери профиля. Передать APK, SHA-256, коммит и результаты сборки. Если будут ещё согласованные изменения UI до сборки, объединить их в один APK. Старая UI-feedback сборка успешно проверена пользователем по трём пунктам, новая ещё не проверялась на телефоне. Финальный полный проход устройства пока ожидается. Собственные игровые звуки в текущем объёме не запланированы, не добавлять независимо.
