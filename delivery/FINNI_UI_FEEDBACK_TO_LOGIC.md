# ДК: пересборка после упрощения интерфейса

Ветка frontend/service-integration. Забрать актуальную ветку обычным merge, без force/reset чужой работы.

Изменены только UI, UI-тесты и документация: inline preview/confirm вместо диалогов обычных действий; отдельный жёлтый экран результата; категорийные рисунки покупок; рисунки ресурсов; понятный план/факт; убраны дубли. Настройки сохраняются без результата-перебивки. Контракт, экономика, SQLite, контент, pubspec и Android не изменялись. Сброс/удаление сохраняют прежние текстовые подтверждения. Запросы используют прежние actionId/revision/generation и warnings. Retry/replay остаются идемпотентными.

Проверено на ПК Ф после финальных правок: flutter analyze --no-pub — 0; flutter test --no-pub --dart-define=FINNI_CAPTURE=true — 20/20. Пять периодов дают прежний финал: 5 доступно, 25 в копилке, 15 баллов, grown. Добавлены проверки изменения суммы после preview, двойного нажатия подтверждения и результата с 200% текстом. Доказательства evidence/ui-feedback; протокол docs/ux/FEEDBACK-REDESIGN.md.

Нужно собрать новый debug APK из lib/main.dart с прежней debug-подписью и package, чтобы участник мог обновиться с сохранением питомца. Передать APK, SHA-256, commit и команды/результаты сборки. Если подпись меняется — предупредить, не предлагать удаление без сохранения доказательств и согласования данных. Старый переданный APK не содержит эти правки. Release готовить после приёмки обновлённого UI.

Пользователь подтвердил Android 16, установку, 100 монет, офлайн-перезапуск; снимки подтверждают первый период 30/30, 3 балла. Пять периодов на физическом устройстве пока не подтверждены.
