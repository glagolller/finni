## Проверенные границы и замечания для Л

- LogicService — интерфейс, реализации пока нет. Строки о готовности экономики, сохранении SQLite и готовом APK нельзя отмечать выполненными.
- Android applicationId/minSdk соответствуют решению ru.finni.pet / 26. APK и связка Gradle/AGP/Kotlin еще не проверены сборкой; анализ Dart не подтверждает работоспособность Android-конфигурации.
- TaskDefinition в Dart содержит criterion. UI не использует критерий и не проверяет ответы; сервис остается единственным местом проверки. Формулировку о том, что criterion вообще не передается UI, нужно согласовать с фактической моделью, но это не блокирует экраны.
- NextActionCode — enum без unknown; безопасное преобразование неизвестных строк должно быть реализовано на границе чтения данных Л. Ф не разбирает свободный текст в команды.
- Нормативный раздел 16 переопределяет части RC2. До финальной документации желательно свести описание в один непротиворечивый текст; сейчас UI использует реальные Dart-типы.
- Необходимы полный сервис и фабрика подключения: listProfiles/loadState/createProfile; каталоги; preview и команды бюджета, покупок, накоплений и целей. Затем задания, периоды, история, settings, reset/delete.
