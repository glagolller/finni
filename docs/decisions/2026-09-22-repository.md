# Подготовка общего репозитория

Участник Ф выбрал GitHub. Подготавливается один локальный репозиторий с документами, без Flutter-каркаса. Для первоначальной удаленной публикации предлагается Private, пустой репозиторий без GitHub-шаблонов. Фактическая удаленная настройка ожидает адрес и авторизацию пользователя.

Файлы с полным ТЗ и персональные бланки остаются вне этой папки. Документы старта перенесены как снимок; личные реквизиты из общей копии плана практики удалены. Состояние требований приложения не изменено.
