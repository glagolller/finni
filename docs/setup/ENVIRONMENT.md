22.09.2026. Это результаты обнаружения, а не проверки сборки приложения.

| Инструмент | Результат |
| --- | --- |
| Git | 2.53.0.windows.3, доступен через комплект среды Codex; доступность в отдельном пользовательском терминале не проверена |
| Автор Git | user.name и user.email не возвращены эффективной конфигурацией; надо задать локально для проекта |
| GitHub CLI | gh не найден в PATH и стандартной папке |
| Java | java сообщает 21.0.9 LTS; в реестре найден JDK 21.0.9 |
| Flutter / Dart | Команды не найдены в PATH, Flutter не найден в проверенных типовых папках |
| Android Studio / SDK | Не найдены в типовых папках и среди отфильтрованных записей установленных программ |
| adb / sdkmanager | Не найдены в PATH |
| ANDROID_HOME / ANDROID_SDK_ROOT / JAVA_HOME / FLUTTER_ROOT | Не заданы в текущем процессе |
| Телефон | Наличие подтверждено пользователем; модель/ОС/ОЗУ/подключение не проверены |

Проверка стандартных мест не исключает нестандартную установку. Существующая Java не доказывает готовность Android toolchain. После согласования версии с Л установить Flutter SDK и Android Studio/SDK, затем выполнить `flutter doctor -v`, проверить устройства и нужные лицензии. Версии фиксировать одинаково; не выбирать независимо разные toolchain. В ходе этого этапа программы, PATH и лицензии не менялись.

Официальная последовательность: https://docs.flutter.dev/platform-integration/android/setup — просмотрено 22.09.2026. Flutter SDK нужен отдельно от плагина редактора. Лицензии Android пользователь должен прочитать и принять. Конкретный набор инструментов и версий определим с владельцем сборки.
