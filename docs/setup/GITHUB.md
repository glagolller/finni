# Подключение GitHub для начинающего

Git — локальная история файлов. GitHub — общий удаленный репозиторий. Репозиторий glagolller/finni уже создан, origin и автор коммитов настроены. Шаги создания ниже — справка, повторять их не нужно. На 24.09 осталось авторизовать Git, отправить документы и подтвердить доступ друга.

## Действия владельца

1. Войти в свой GitHub и открыть https://github.com/new.
2. Название: `finni` (можно другое, тогда передать фактическую ссылку). Видимость: Private на этапе подготовки.
3. Не добавлять README, .gitignore, лицензию или автоматически созданный код: локальные документы уже подготовлены.
4. Создать пустой репозиторий, скопировать URL вида https://github.com/LOGIN/finni и передать его Codex Ф.
5. В Settings → Collaborators → Add people пригласить точный аккаунт друга. Друг должен принять приглашение. Если интерфейс называет раздел иначе, искать управление доступом репозитория.

Создание учетной записи, если ее еще нет, участник выполняет самостоятельно. Пароли, токены, коды и ключи не вставлять в чат. Для авторизации Git использовать штатный вход GitHub, когда он понадобится.

## Что передать Codex Ф

- Ссылку на созданный пустой репозиторий.
- Точный GitHub-логин друга и факт принятия приглашения.
- Имя автора коммитов и email для Git. Можно использовать свой GitHub noreply-адрес из Settings → Emails; не придумывать его по логину.

Имя/email автора коммита не заменяют вход в GitHub. Настроим их локально для этого проекта, не меняя настройки других работ.

## Дальнейшие действия агента

Проверить URL/состояние удаленного репозитория, задать локальную идентичность, просмотреть состав первого коммита, сохранить документы, добавить origin и отправить main после штатной авторизации. Ничего не перезаписывать, если удаленный репозиторий неожиданно содержит историю. Проверить наличие файлов и доступ друга. Затем друг клонирует общий репозиторий и создает каркас в своей ветке по отдельному поручению.

Защита ветки и доступ экспертов настраиваются отдельно. Private означает, что одной ссылки недостаточно для жюри: предоставить доступ по согласованной с организатором процедуре до сдачи.
