# Матрица требований

Дата базовой версии: 22.09.2026. Все функции и сдаваемые результаты пока не начаты. Подготовка этой матрицы — планирование, а не выполнение требования D05 о соответствии готового продукта.

Источник без префикса — раздел исходного ТЗ S1. В P03–P05 запись «4.1–4.3» и подобная означает пункты перечня содержания презентации внутри §4, а не подраздел обязательной демонстрации §4.1. S2, S5 и S8 описаны в `01-scope.md`. Уточнения S8 внесены 24.09.2026. Рекомендации и условные требования помечены отдельно. Ведущий отвечает за результат строки, совместные строки делятся по `01-scope.md`.

Плановое место — будущий экран/модуль/материал, не существующий код. В доказательство после реализации вписывают относительный путь + версию/коммит + ссылку на проведенную проверку. Для условной строки после согласованного отказа от функции ставят проверку «не применимо» с объяснением; не выдают ее за реализованную.
