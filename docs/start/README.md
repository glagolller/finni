# Стартовый пакет проекта «Питомец Финни»

Версия 1.0 от 22 сентября 2026 года. Этап: подготовка требований. Приложение не реализовано; репозиторий, стек, сборка и доступ экспертов еще не настроены. Этот пакет содержит проектные документы, а не готовый продукт или заполненные отчеты о разработке.

Цель команды: создать Android-прототип по задаче Департамента финансов Москвы и использовать подтвержденные результаты для двух индивидуальных отчетов и дневников учебной практики. Приоритет учебной практики задан участником; конкурсные требования сохраняются.

## С чего начать

1. Прочитать [границы и ответственность](01-scope.md).
2. Передать другу всю папку `finni-start` и [стартовое сообщение](08-friend-prompt.md). Личные бланки передавать только при необходимости; в пакет они не скопированы.
3. Согласовать стек, владельца Android-сборки и [договор взаимодействия](04-contract.md).
4. Создать общий репозиторий и применить [правила совместной работы](05-collaboration.md).
5. Выполнять [план 22–29 сентября](09-plan.md), обновляя матрицу и реальные результаты.

## Обозначения

- **Ф** — участник, отвечающий за интерфейс, и его Codex.
- **Л** — друг, отвечающий за игровую логику и локальное хранение, и его Codex.
- **К** — капитан команды; личность пока не указана.
- **Ф+Л** — совместная задача с отдельными результатами каждой стороны.
- **О** — обязательное требование. **У** — действует при указанном условии. **Р** — рекомендация источника. **П** — предложение команды, не требование организатора.

Статусы матрицы: «не начато», «в работе», «реализовано». Отдельная колонка проверки: «не проверено», «пройдено», «не пройдено», «не применимо» с обоснованием. Реализация без проверки не означает готовность к сдаче. Ссылки на будущие модули и экраны в пакете — плановые назначения, а не свидетельство их существования.
