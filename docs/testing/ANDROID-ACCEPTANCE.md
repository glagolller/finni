## Установка без компьютера

1. Передать на телефон именно этот APK из сообщения ДК (SHA-файл устанавливать не нужно). Открыть APK через «Мои файлы» или приложение, куда он сохранён.
2. Если Android запросит разрешение установки из этого источника, прочитать системный диалог и разрешить только выбранному приложению. После установки разрешение можно выключить. Если установка заблокирована — прислать точный текст; не отключать защиту телефона целиком.
3. Нажать «Установить», затем открыть Финни с иконки. Если приложение уже установлено и обновление не проходит — сохранить сообщение ошибки, пока не удалять приложение и его данные.
4. Должен открыться игровой интерфейс без надписи тестового просмотра. Создать отдельное «Демо: пять периодов», затем «Начать дружбу». Исходный доступный баланс — 100.

## Первые 10 минут

Создать тестовый демопрофиль, выбрать цель «Игровая площадка для Финни · 120 монет». Выполнить первый период по таблице ниже, пока не завершать его. Сохранить снимок балансов и текущего периода. Включить авиарежим и отдельно убедиться, что Wi-Fi выключен. В настройках Android открыть приложение Финни и нажать «Остановить», затем снова запустить с иконки. Профиль и состояние должны сохраниться без повторного начисления дохода. Не очищать данные/хранилище. Продолжить сценарий без интернета.

## Пять периодов через интерфейс

В каждом периоде: «Дом» → «Мой бюджет», заполнить три суммы → «Посмотреть план» → «Подтвердить» → «Продолжить». Затем задания, покупки, пополнение копилки. Для каждой покупки/пополнения подтвердить предпросмотр. В конце «Дом» → «Итог периода» → «Завершить период» → «Подтвердить» → «Продолжить». До пятого периода нажимать «Начать следующий период». ## Ошибки, удобство и настройки

- В периоде 1 после пополнения попробовать музыкальную игрушку: средств не хватает, подтверждения покупки нет. Баланс не меняется.
- Предпросмотр снятия 10 монет → отмена: баланс не меняется.
- В периоде 3 сначала отметить всё желаемым: награды нет; исправить ответ по таблице и получить награду один раз.
- В задании заполнить поля → справка → вернуться: введённое сохраняется.
- Проверить системную кнопку/жест «Назад», клавиатуру внизу экрана, прокрутку, доступность кнопок. Ошибку фиксировать снимком и последовательностью действий.
- Увеличить системный шрифт и включить крупный текст игры; проверить главную, задания, подтверждение и настройки. Вернуть привычный размер после проверки.
- Проверить TalkBack: названия кнопок/значков и порядок фокуса. Проверить переключатели звука и уменьшения движения. Успешное переключение не доказывает фактический звук/доступность.
- После сохранения результатов войти во взрослый раздел (8+7=15). Сначала отменить сброс и проверить сохранность. Затем на тестовом профиле подтвердить «СБРОСИТЬ»: первый период, 100 монет. Удаление с «УДАЛИТЬ» возвращает к выбору/созданию профиля; другие профили не должны исчезать.

## Протокол участника

Заполнить и прислать ответом, можно по частям:

```text
Android / One UI:
Дата проверки:
Установка и первый запуск: успешно / ошибка (текст)
Демо после первого запуска: 100 монет / другое
Периоды 1–5: фактические балансы и стадии (или последний пройденный)
Авиарежим + принудительная остановка: состояние сохранено / ошибка
Получение цели и история:
Назад / клавиатура / крупный шрифт:
Звук / уменьшение движения / TalkBack: проверено (результат) / не проверено
Отмена / сброс / удаление тестового профиля:
Ошибки: экран, шаги, ожидаемое и фактическое
Скриншоты или запись экрана:
```

Холодный запуск и задержку покупки измерять отдельно, с описанием способа и несколькими попытками. Debug-показатели не подтверждают нормативы release. Финальную приёмку, скриншоты сдачи и видеодемонстрацию повторить на подписанной release-сборке. Обновление debug на release может требовать удаления из-за разных подписей: заранее сохранить доказательства и согласовать потерю тестовых данных.
