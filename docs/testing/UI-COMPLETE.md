# Игровой UI: сквозная проверка 25–26.09.2026

Ветка frontend/service-integration. Сервис и экономика ДК из PR #4, без изменений lib/contracts, lib/domain, lib/data и игрового контента. Проверка завершена и оформлена 26.09.2026. Реализация UI выполнена с помощью Codex.

## Фактические проверки

- flutter analyze --no-pub: 0 замечаний.
- flutter test --no-pub --dart-define=FINNI_CAPTURE=true: 17/17, около 60 секунд.
- Полный сценарий test/full_ui_demo_test.dart использует SqliteLogicService + SQLite FFI, а действия выполняет через Flutter-виджеты при 360×800. Прямые чтения сервиса служат только для сверки результата. Профиль, план, ответы, покупки, переводы, смена периодов, получение цели и взрослые действия выполняются нажатиями/вводом.
- Пройдены все шесть типов заданий. Неверная классификация не дала награды; исправление прошло. Вызов справки сохранил введённые суммы задания. После завершения демо задание доступно только для просмотра.
- Отмена снятия не изменила revision. Недостаток монет не даёт кнопки подтверждения. Взрослый барьер отвергает неверный ответ; отмена reset сохраняет generation; подтверждение reset увеличивает его на один и возвращает доход 100; delete удаляет профиль и возвращает экран знакомства.
- Крупный текст сохранён настоящим сервисом и применяется; история загрузила следующую страницу. Прежние тесты проверяют сохранение после повторного открытия SQLite, replay/conflict, блокировку двойной команды и устаревших снимков, стадии питомца и отсутствие overflow на главном экране при 200% текста.

Контроллер ввода подтверждения теперь принадлежит отдельному диалогу и удаляется вместе с ним без искусственной задержки. Исправлена потеря черновика задания при возврате из справки. Первые неудачные тестовые прогоны не считаются успешными.
