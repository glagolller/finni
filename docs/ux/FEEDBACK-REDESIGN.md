# Переработка обратной связи после проверки Android

26.09.2026. Основание: девять скриншотов пользователя, первый период debug APK на Galaxy A34 5G / Android 16. На снимках 30 доступно, 30 накоплено, 3 балла, сытость 65, настроение 84. Полная приёмка пяти периодов на телефоне не заявляется.

## Изменения

- Обычный предпросмотр встроен на место кнопки: первое нажатие читает preview, второе «Подтвердить» выполняет команду. Видны ненулевые изменения ресурсов и предупреждения сервиса. Есть отмена. Сетевой/дисковый запрос нельзя обойти быстрым двойным нажатием.
- Подтверждение сбрасывается при изменении суммы или переходе на другой экран. Команда использует исходные revision/generation и одно actionId; повтор после неизвестного исхода сохраняет прежний ID. Отмена не вызывает запоздалый возврат в каталог.
- Результат — отдельный жёлтый экран: большая монетка для награды, общие рисунки еды/игрушек/ухода/здоровья/одежды/декора для покупок. Награда берётся из сервиса, не фиксируется как +5 в UI. Replay не изображает новое начисление. Пояснения раскрываются через «Почему?», совпадающие строки удалены.
- Настройки больше не требуют закрывать результат после каждого переключения.
- План и факт подписаны отдельно. «Желания 20 / 0» означали план 20, потрачено 0: экономической ошибки по сценарию нет. Повтор балансов на экране завершения убран.
- ResourceText заменяет видимые упоминания монет, сытости, настроения и баллов рисунками. Исходные слова сохранены для экранного диктора. Названия разделов и учебные понятия «бюджет», «накопления» сохраняют смысл. Рисунки кодовые, локальные; новых зависимостей и внешних изображений нет.

## Ограничения ТЗ

F19: снятие накоплений по-прежнему отдельно подтверждается с видимым изменением копилки. U07: сброс и удаление сохраняют текстовое подтверждение. F07/F25: источник награды и объяснение доступны; полностью удалять образовательную обратную связь нельзя. Контракт, экономика, SQLite и Android-конфигурация не изменялись.

Снимки evidence/ui-feedback — widget-рендер на ПК, не новая Android-сборка. Старые evidence/ui-complete и HTML-прототип оставлены как исторические версии. ## Ведение ребёнка — варианты, пока не реализованы

1. Карточка «Сейчас попробуй…» с одной кнопкой на главной. Подсказка выбирается из текущего состояния: план, нужная покупка, копилка, итог. Можно играть свободно. Наименьший объём: UI, правила приоритета, тесты состояний.
2. Список дел периода с отметками и переходами. Даёт обзор и свободу порядка. Средний объём: несколько условий завершения, повторное открытие/перезапуск, варианты неуспешного периода.
3. Короткое обучение первого периода с подсветкой кнопок и возможностью пропустить/повторить. Объясняет управление, но не заменяет помощь в следующих периодах. Больший объём: фокус, Back, крупный шрифт, сохранение шага (координация с Л).
4. Сюжетные просьбы Финни и цепочки миссий. Самая сильная мотивация, наибольший объём контента/состояний/тестов; потребуются договорённости с Л, без самовольного изменения экономики.

Предложение для срока хакатона: 1 + компактный список 2. Это рекомендация, не выполненная функция. Ни голод вне игры, ни наказания за отсутствие, ни таймеры давления не добавляются.
