# Подсказка следующего действия и список дел

26.09.2026. HomeGuidance читает GameState и getItemCatalog через LogicService. Никакие команды изменения состояния из подсказки не отправляются; кнопка открывает существующий экран. Экономика, контракт, база и контент не изменены.

Приоритет: завершённое демо → история; закрытый период → итог; нет плана → бюджет; нужны покупки → доступный по цене нужный товар; при нехватке средств → доступное ненаграждённое задание, затем рассмотрение копилки или итог. Исчерпанный лимит не направляет обратно в магазин. После нужных покупок доступна полученная цель; далее необязательное задание, накопления по плану и итог. Подсказка не обещает награду при отсутствии доступных заданий и не предлагает новый доход в завершённом демо.

Отметки списка дел читают наличие плана, fulfilled обязательных покупок, qualifyingSavings относительно savingsTarget и статус периода. Задание отмечается отдельно по награде текущего периода, завершённые ранее задания не представляются как вновь выполненные. Список не является оценкой ребёнка и не блокирует любые другие разделы.

При смене профиля, поколения или ревизии каталог перечитывается. При ошибке чтения есть повтор и пояснение; свободная навигация сохраняется. Никакие новые флаги прохождения обучения не записываются: при перезапуске подсказка восстанавливается из сохранённого состояния. Доступность действий по-прежнему проверяет сервис в preview/command.
