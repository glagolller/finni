HTML — независимые примеры, не работающая экономика. Flutter подключён к реальному сервису: игровые сценарии реализованы и прошли проверку на ПК; APK ожидается. Шрифты Pangolin/Neucha, цветные значки, фиксированная область питомца с тремя стадиями. Подробности ограничений в CHILD-DESIGN.md.

Макеты и UI относятся к индивидуальной части Ф. Л документирует собственные модели, экономику и хранение. Журналы не заменяют подписанные отчёты/дневники.
