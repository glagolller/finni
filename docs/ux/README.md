# Интерфейс Финни

Актуальный дизайн v0.2 от 25.09.2026: [решения, соответствие ТЗ и проверки](CHILD-DESIGN.md).

- [Кликабельный макет](prototype-v0.1.html): 35 экранов/состояний, прежнее имя файла сохранено. Открой браузером и обнови Ctrl+F5. Для автономной передачи нужна вся папка проекта: шрифты лежат в assets/fonts.
- [27 вариантов взросления](pet-growth.html): все формы, окраски и стадии.
- [Спецификация экранов](screen-spec.md), [навигация](navigation.md).
- [Реализованная часть Flutter](IMPLEMENTATION.md).
- [Новые снимки Flutter](../../evidence/ui-child/); [исторические проверки v0.1](../../evidence/ui-v0.1/QA.md).

HTML — независимые примеры, не работающая экономика. Flutter — первая часть UI с тестовыми состояниями; реальный сервис и APK ожидаются. Шрифты Pangolin/Neucha, цветные значки, фиксированная область питомца с тремя стадиями. Подробности ограничений в CHILD-DESIGN.md.

Макеты и UI относятся к индивидуальной части Ф. Л документирует собственные модели, экономику и хранение. Журналы не заменяют подписанные отчёты/дневники.
