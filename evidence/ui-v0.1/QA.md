# Проверка макетов v0.1

Дата 24.09.2026. Среда: встроенный браузер Codex, viewport 360×800 CSS px, локальный HTTP только 127.0.0.1. Это не Android, не проверка APK и не исследование с детьми.

| Проверка | Наблюдение |
|---|---|
| Главный E03 | На снимке одновременно видны питомец, состояние, доступные монеты, накопления, цель и следующее задание |
| Создание E02 | Переключение формы 1 → 3 и палитры 1 → 3 изменяет SVG и семантическую подпись изображения |
| Бюджет E04 | Поля и пример распределения видны; кнопка открывает S_PLAN с последствиями подтверждения |
| Навигация по #ID | При первой проверке смена hash не меняла экран; добавлен обработчик hashchange и повторно проверен переход E02 → E04 |
| Крупный текст | Переключатель E13 увеличивает текст; на E03 карточки расширяются по высоте, нижние действия доступны прокруткой |
| Узкий обзорный режим | При первой проверке обнаружено горизонтальное растяжение grid; добавлен min-width:0 для main/aside. Для проверки самого телефона использован отдельный device-режим |

Сохранены E02-create-360.png (выбранная форма 3, палитра 3), E03-home-360.png (профиль-образец формы 1, палитры 1), E04-budget-360.png. Разные изображения — независимые состояния макета, не доказательство сохранения пользовательского выбора в приложении.

Ограничения: не проверены TalkBack, физический Android, системный Back/клавиатура, 200% системного шрифта, доступность каждого элемента, запуск за 5 секунд и отклик за 1 секунду. Кнопки макета показывают статичные сценарии, не рассчитывают деньги и не вызывают хранилище. Формы и подтверждения — дизайн, не проверенный API.
